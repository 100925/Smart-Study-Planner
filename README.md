#  Smart Study Planner

A simple and user-friendly web application to organize study schedules, manage subjects, track study progress, and improve productivity.

##  Live Website

 **Try the Website:** https://smart-study-planner-86jt.bolt.host

##  Features

-  Add study plans with subjects, topics, dates, and duration.
-  Mark study tasks as completed or pending.
-  Dashboard to track total tasks, completed tasks, pending tasks, and progress percentage.
-  Filter study plans by subject and task status.
-  Simple and user-friendly interface.
-  Manage study plans and track your learning progress.

##  Project Objective

The main objective of Smart Study Planner is to help students organize their daily study activities, manage time effectively, and monitor their academic progress in one place.

##  Technologies Used

- Frontend: React / JavaScript / CSS (as used in the project)
- Development and Deployment: Bolt.new
- Version Control: Git and GitHub

##  How to Use

1. Open the live website.
2. Add a study plan with the subject, topic, date, and duration.
3. Track your study tasks from the dashboard.
4. Mark tasks as completed when you finish them.
5. Filter tasks to view your study progress.
